# Horacio Abitú — Portfolio & Soluciones Digitales

Sitio web y portfolio profesional de **Horacio Abitú**, Desarrollador Full Stack e integrador de Inteligencia Artificial. Construido con tecnologías modernas para ofrecer una experiencia rápida, accesible y de alto impacto visual.

---

## 🚀 Tecnologías

- **Framework:** [Next.js 15](https://nextjs.org/) (App Router)
- **Librería UI:** [React 19](https://react.dev/)
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
- **Componentes:** Inspirados en [Shadcn UI](https://ui.shadcn.com/) (Radix UI + CVA + Tailwind Merge)
- **Íconos:** [Lucide React](https://lucide.dev/)
- **Gestor de Paquetes:** [pnpm](https://pnpm.io/)
- **Alojamiento Multimedia:** [Cloudinary](https://cloudinary.com/) (optimización de imágenes remotas)

---

## ✨ Características y Secciones

- **Hero:** Presentación de impacto con llamadas a la acción directas hacia WhatsApp y proyectos.
- **Servicios:** Soluciones en desarrollo web full stack, UX/UI, aplicaciones web y móviles, automatización con IA y consultoría IT.
- **Proyectos Destacados:** Muestra de desarrollos principales (Historias Clínicas SaaS, Portal de la Cámara de Industria y Comercio, CafeRestoPOS) con capturas de pantalla y enlaces directos a producción.
- **Otros Proyectos (`/otros-proyectos`):** Página complementaria con proyectos adicionales (Rawson Chubut Vivilo, FM Bahía Engaño, Cecilia María Aliaga, Conferencia ADN 2026).
- **Sobre mí:** Trayectoria, filosofía de desarrollo y stack tecnológico.
- **Contacto & Agenda:** Canales de comunicación directa mediante Google Calendar, WhatsApp y correo electrónico corporativo.
- **Diseño & Rendimiento:** Paleta moderna en modo oscuro, tipografía optimizada, navegación responsive y soporte SEO con etiquetas Open Graph.

```text
│   └── ui/                  # Componentes de interfaz (Button, Card)

└── tailwind.config.js       # Configuración y temas de Tailwind CSS
```

## 🛠️ Instalación y Desarrollo Local

### Requisitos previos
- [Node.js](https://nodejs.org/) v20.9 o superior
- [pnpm](https://pnpm.io/) (recomendado) o npm

### Pasos

1. Clonar el repositorio:
```bash
git clone https://github.com/dev-back55/Horacio-Portfolio-aisolutions-2026.git
cd Horacio-Portfolio-aisolutions-2026
```

2. Instalar dependencias:
```bash
pnpm install
# o con npm:
# npm install
```

3. Iniciar el servidor de desarrollo:
```bash
pnpm dev
# o con npm:
# npm run dev
```

4. Abrir en el navegador: [http://localhost:3000](http://localhost:3000)
